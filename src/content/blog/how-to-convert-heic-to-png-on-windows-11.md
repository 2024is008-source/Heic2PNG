                  <h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">1. Why Windows 11 Sometimes Rejects HEIC Files</h2>
                  <p class="text-[#64748B] mb-3">
                    Since iOS 11, iPhones capture photos in <strong class="text-[#0F172A]">HEIC (High Efficiency Image Coding)</strong> by default. Because HEIC relies on the patent-encumbered HEVC (H.265) video compression standard, fresh Windows installations do not always bundle both the container parser (<em>HEIF Image Extensions</em>) and the video decoder (<em>HEVC Video Extensions</em>).
                  </p>
                  <p class="text-[#64748B]">
                    Even if your Windows 11 PC can preview a <code class="font-mono text-xs bg-slate-100 px-1.5 py-0.5 rounded">.heic</code> file in File Explorer, many third-party Windows applications and web upload portals still require a standard <strong class="text-[#0F172A]">PNG</strong> or <strong class="text-[#0F172A]">JPG</strong> image.
                  </p>

                  <h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">3. Method 2: Use the Built-In Windows 11 Photos App</h2>
                  <p class="text-[#64748B] mb-3">
                    If you only need to convert a single image and already have the HEIF/HEVC extensions installed on Windows 11:
                  </p>
                  <ol class="space-y-2.5 text-sm text-[#64748B] list-decimal pl-5">
                    <li>Right-click the <code class="font-mono text-xs">.heic</code> file in File Explorer and choose <strong>Open with → Photos</strong>.</li>
                    <li>Press <kbd class="px-1.5 py-0.5 rounded bg-slate-100 border border-slate-300 font-mono text-xs text-[#0F172A]">Ctrl + Shift + S</kbd> (or click the three-dot menu and select <strong>Save as</strong>).</li>

                <div id="art-sec-5" class="scroll-mt-24">
                  <h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">5. Verifying File Extensions &amp; Troubleshooting Failed Files</h2>
                  <p class="text-[#64748B] mb-3">
                    Sometimes a file named <code class="font-mono text-xs">.heic</code> won't open because it is actually a renamed JPEG or an incomplete iCloud placeholder file. You can inspect all <code class="font-mono text-xs">.heic</code> files in a Windows folder and check their sizes using PowerShell:
                  </p>
                  <pre class="rounded-xl bg-[#0F172A] text-slate-100 p-4 font-mono text-xs overflow-x-auto mb-4"><code># List all HEIC files in your Pictures folder and check for 0-byte iCloud stubs
Get-ChildItem -Path "$env:USERPROFILE\Pictures" -Filter *.heic |
  Select-Object Name, @{Name="SizeMB";Expression={[math]::Round($_.Length / 1MB, 2)}}, LastWriteTime</code></pre>
                  <!-- Warning & Troubleshooting Note -->
                  <div class="rounded-xl bg-amber-50 border border-amber-200 p-4 text-xs sm:text-sm text-slate-800">
                    <strong class="text-amber-900">Troubleshooting Note (iCloud "Download Required" Stubs):</strong> If a HEIC file shows a size of only a few kilobytes on Windows, right-click the file in iCloud Photos and select <strong>Always keep on this device</strong> before converting.
                  </div>

                    <div class="p-4 rounded-xl bg-[#F8FAFC] border border-[#E2E8F0]">
                      <h3 class="font-bold text-[#0F172A]">Does changing the file extension from .heic to .png in File Explorer work?</h3>
                      <p class="text-xs sm:text-sm text-[#64748B] mt-1">No. Manually renaming <code class="font-mono text-xs">photo.heic</code> to <code class="font-mono text-xs">photo.png</code> only changes the filename label; the internal data remains HEVC-encoded and will trigger corruption errors in editors. Always run an actual format conversion.</p>
