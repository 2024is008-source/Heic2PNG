              <div class="space-y-8 text-[#0F172A] leading-relaxed text-[15px]"><div id="art-sec-1" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Choose the file you actually want to export</h2><p class="text-[#64748B] mb-3">Start by locating the image. A file in Downloads or an AirDrop folder is different from an item managed inside Photos. If your library uses optimized storage, allow the original to download before exporting. A thumbnail that looks complete on screen is not evidence that a full local original is available for conversion.</p><p class="text-[#64748B] mb-3">Also decide whether you want the edited appearance or the untouched capture. A crop or color adjustment in your library may be part of the picture you intend to send. Exporting an unmodified original is useful for preservation, but it does not apply your chosen PNG format and may give you another HEIC. Treat a PNG as a delivery or editing copy, not as a backup of the entire library item.</p></div>
<div id="art-sec-2" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Export one HEIC as PNG in Preview</h2><ol class="space-y-2.5 text-sm text-[#64748B] list-decimal pl-5 mb-3"><li>In Finder, select your HEIC and open it with Preview. If another app opens by default, use Open With to select Preview.</li><li>Choose File &gt; Export.</li><li>Choose PNG in the Format menu. Apple notes that holding Option while opening that menu reveals additional formats when needed.</li><li>Give the copy a useful name and select a destination folder. Keep the .png extension supplied by the export.</li><li>Save, then open the resulting PNG independently to check its orientation and content.</li></ol><p class="text-[#64748B] mb-3">These steps follow <a href="https://support.apple.com/guide/preview/convert-image-file-types-prvw1012/mac" class="text-[#4F46E5] font-semibold underline">Apple’s Preview conversion instructions</a>. Menu details can vary with macOS and the source file. If you land in a print or PDF dialog, cancel it and return to the image export command. Creating a PDF containing a photograph does not produce a PNG image.</p><p class="text-[#64748B] mb-3">Save exports in a folder such as “PNG copies” and check that the originals still exist. If a save dialog warns that a filename already exists, choose a different name or folder unless replacement is intentional. Reopen the saved output rather than judging a Preview window that may still display the HEIC.</p></div>
<div id="art-sec-3" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Convert several images or export from Photos</h2><p class="text-[#64748B] mb-3">Open the selected HEIC files together in one Preview window, select the intended thumbnails in its sidebar, then use the documented export steps. If the files open separately, review Preview > Settings > Images for the grouped-window option. Check the selected count, output folder and PNG format before saving the batch.</p><p class="text-[#64748B] mb-3">For library photos, use Photos: select the items, choose File &gt; Export &gt; Export Photos, then choose PNG under Photo Kind. Review size and color-profile options offered by your version and export to a folder. <a href="https://support.apple.com/guide/photos/export-photos-videos-and-slideshows-pht6e157c5f/mac" class="text-[#4F46E5] font-semibold underline">Apple documents the Photos format and size controls</a>. Avoid “Export Unmodified Original” when the purpose is specifically a PNG conversion.</p><p class="text-[#64748B] mb-3">After a batch, compare the number of outputs with the number of intended still images. Live Photos and other compound items do not necessarily correspond to one interchangeable file. Look for duplicate names and skipped items instead of assuming that the presence of a folder means the whole job succeeded.</p></div>

                </div><div id="art-sec-4" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Use the browser converter when it fits your workflow</h2><p class="text-[#64748B] mb-3">The <a   href="/" class="text-[#4F46E5] font-semibold underline inline-block text-center">HEIC to PNG converter</a> is another option when you want the same conversion interface across several computers. Select locally available HEIC files, keep original resolution unless resizing is intentional, convert, and download either individual PNGs or the batch ZIP. The converter processes photo data on your device in the browser.</p><p class="text-[#64748B] mb-3">Check one result before queuing many large images. Decoding requires working memory, and the output may be substantially larger than the input. If the browser becomes unresponsive, try a smaller batch and close memory-heavy tabs. A ZIP download packages the outputs; extracting it is still necessary before most upload forms can use the individual pictures.</p><p class="text-[#64748B] mb-3">This route exports an 8-bit RGB primary image and strips EXIF. It does not preserve source ICC/HDR processing or guarantee auxiliary layers. Choose a color-managed native workflow when you need controlled rendering, and keep the source for future exports. The browser route is useful for compatibility copies, not a promise of complete photo-library fidelity.</p></div>
<div id="art-sec-5" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Check dimensions, color and file size</h2><ul class="space-y-2.5 text-sm text-[#64748B] pl-5 mb-3"><li>Open the exported PNG and confirm that no unwanted crop, border or rotation was introduced.</li><li>Compare pixel dimensions with your intended output. A change in the reported print DPI is not the same as a change in pixel count.</li><li>Review important colors and bright areas in the application where the PNG will be used.</li><li>Check the file size against any upload limit before sending the whole batch.</li></ul><p class="text-[#64748B] mb-3">PNG uses lossless image compression, but that description applies to the pixel samples given to its encoder. It does not mean that every aspect of the HEIC source has survived the decoding and export path. Nor does a larger PNG contain recovered camera detail. Read <a href="/blog/heic-vs-png-quality-file-size-compatibility/" class="text-[#4F46E5] font-semibold underline">why converted PNGs can be much larger</a> if the size increase is surprising.</p><p class="text-[#64748B] mb-3">For a photo-only form with a tight limit, <a  href="/heic-to-jpg/" class="text-[#4F46E5] font-semibold underline inline-block text-center">JPG output</a> may be a better fit. Use the required format rather than choosing PNG simply because it sounds higher quality. Avoid repeatedly converting between formats while trying to meet a limit; return to the original for each export.</p></div>
<div id="art-sec-6" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Troubleshoot a missing format or failed export</h2><p class="text-[#64748B] mb-3">If PNG is missing, confirm that you opened an image in Preview and are using Export rather than a document-specific command. Try the Format menu with Option held. If Photos only exports HEIC, check that you chose a selected-format export instead of an original-file export.</p><p class="text-[#64748B] mb-3">If the image will not open at all, download it again from the original source and check its file size. A cloud placeholder, incomplete transfer or renamed non-image cannot be repaired by choosing PNG. For files shared by someone else, request the original again before changing extensions. The <a href="/blog/how-to-fix-heic-files-that-wont-open/" class="text-[#4F46E5] font-semibold underline">HEIC troubleshooting guide</a> explains how to separate a decoder problem from a damaged file.</p><p class="text-[#64748B] mb-3">When several files have similar names, test the exact exported file you intend to send. A preview window can remain open on the HEIC while Finder highlights a PNG nearby. Closing the old window and reopening the output removes that ambiguity.</p></div>
<div id="art-sec-7" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Mac HEIC to PNG FAQ</h2><div class="space-y-3 text-sm"><div class="p-4 rounded-xl bg-[#F8FAFC] border border-[#E2E8F0]"><h3 class="font-bold text-[#0F172A]">Can I rename .heic to .png in Finder?</h3><p class="text-xs sm:text-sm text-[#64748B] mt-1">No. Renaming changes the label, not the encoded image. Use an export that actually writes PNG data.</p></div><div class="p-4 rounded-xl bg-[#F8FAFC] border border-[#E2E8F0]"><h3 class="font-bold text-[#0F172A]">Will converting to PNG make my photo sharper?</h3><p class="text-xs sm:text-sm text-[#64748B] mt-1">No. PNG can avoid further lossy compression of the rendered pixels, but it cannot restore detail missing from the capture or an earlier edit.</p></div><div class="p-4 rounded-xl bg-[#F8FAFC] border border-[#E2E8F0]"><h3 class="font-bold text-[#0F172A]">Must I install a converter?</h3><p class="text-xs sm:text-sm text-[#64748B] mt-1">For a supported HEIC image on a compatible Mac, Preview or Photos may already provide the needed export. The browser converter is an alternative, with the limitations described above.</p></div></div></div>
<div id="art-sec-8" class="scroll-mt-24"><h2 class="text-xl sm:text-2xl font-extrabold text-[#0F172A] mb-3">Finish with a verified copy</h2><p class="text-[#64748B] mb-3">Use Preview for standalone files, Photos for a library selection, or a browser conversion for a consistent batch workflow. Keep the original, choose PNG explicitly and reopen the result. If your actual requirement is a small website photograph, compare <a href="/blog/heic-to-jpg-vs-png-which-format-should-you-choose/" class="text-[#4F46E5] font-semibold underline">JPG, PNG and AVIF</a> before exporting an entire library.</p><ul class="space-y-2.5 text-sm text-[#64748B] pl-5 mb-3"><li><a href="https://support.apple.com/guide/preview/convert-image-file-types-prvw1012/mac" class="text-[#4F46E5] font-semibold underline">Apple: Preview image format conversion</a></li><li><a href="https://support.apple.com/guide/photos/export-photos-videos-and-slideshows-pht6e157c5f/mac" class="text-[#4F46E5] font-semibold underline">Apple: Photos export options</a></li><li><a href="https://www.w3.org/TR/png-3/" class="text-[#4F46E5] font-semibold underline">W3C: PNG specification</a></li></ul></div></div>
